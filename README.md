# Site — Francieli Manfio Arquitetura

Site estático (HTML/CSS/JS puro), pronto para Vercel. One-page com tom de arquitetura humanizada.

- `index.html` — início, sobre, valores, como trabalho, serviços, projetos, depoimentos, contato
- Abertura animada com a logo (some sozinha em ~3 s, também sem JS) e cursor animado (só em mouse; desativado com "reduzir movimento")
- `assets/style.css`, `assets/main.js`, fotos em JPG (tiradas do Instagram @francielimanfioarquiteta, 640 px)
- `vercel.json` — cabeçalhos de segurança
